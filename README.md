# yash8418.github.io

Personal portfolio of **Yash Prajapati**: software developer & data analyst, Master of Applied Computing student at the University of Windsor.

**Live:** https://yash8418.github.io/

- Plain HTML, CSS and a little JavaScript: no framework or build step, so it loads fast
- Light and dark themes, keyboard and screen-reader friendly, respects reduced-motion settings
- Search-ready: page metadata, link-preview image, `Person` structured data linking LinkedIn and GitHub, sitemap

## Run locally

```bash
python -m http.server 8000   # then open http://localhost:8000
```

## Structure

```
index.html        # the whole site
styles.css        # design tokens, layout, light/dark themes
main.js           # theme toggle, project filters, scroll reveal
assets/           # favicon, link-preview image, project screenshots, resume
robots.txt, sitemap.xml, 404.html
```
