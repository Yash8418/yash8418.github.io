Within24

International students in Canada can work 24 hours a week off campus, but hours from several jobs and gig apps add up and no one sees the total. AWS serverless pipeline

Border Wait Live

CBSA stopped publishing hourly border history after 2019. This pipeline collects live wait times for all 29 Canada–US land crossings every 15 minutes and serves them through a public API and a live status page.

  • EventBridge Scheduler → Lambda → single-table DynamoDB with conditional writes, so repeated readings are never duplicated
  • Infrastructure as code with AWS SAM, least-privilege IAM, CloudWatch alarm + SNS alerts
  • 38 tests with moto; estimated running cost under $0.10 a month
  • AWS Lambda
  • DynamoDB
  • AWS SAM
  • Python
  • CI/CD

Data analysis

Windsor–Detroit Border Wait Analysis

When is the border busiest? I analysed 153,875 hourly CBSA readings (2010–2019) for the Ambassador Bridge and the Detroit–Windsor Tunnel and published an interactive dashboard with a best time to cross planner.

  • Friday 6 pm is the worst hour — the Bridge was delayed 55% of the time
  • Summer has about 3× the delays of winter; holidays raise Tunnel delays 1.7×
  • Analysis written as tested SQL in DuckDB; CI rebuilds everything from raw data
  • Python

  • SQL (DuckDB)
  • matplotlib
